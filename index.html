RuneScape 3 language switch

Click a link to start the client in that language.

Before switching: close the Jagex Launcher completely via the taskbar / system tray. Otherwise the link reuses the running launcher and the language won't change.
  • English jagex:launch=runescape,args=[configURI=rs-launch://www.runescape.com/k=5/l=0/jav_config.ws]
  • German jagex:launch=runescape,args=[configURI=rs-launch://www.runescape.com/k=5/l=1/jav_config.ws]
  • French jagex:launch=runescape,args=[configURI=rs-launch://www.runescape.com/k=5/l=2/jav_config.ws]
  • Portuguese jagex:launch=runescape,args=[configURI=rs-launch://www.runescape.com/k=5/l=3/jav_config.ws]
  • Beta jagex:launch=runescape,args=[configURI=rs-launch://www.runescape.com/jav_config_beta.ws]
  • Plugin API BetaWorld 204 jagex:launch=runescape,args=[configURI=rs-launch://world204.runescape.com/jav_config_beta.ws]
